# ローカルの旅程編集

共同サーバーへの接続を遮断したローカル専用ランチャーで起動する。プロジェクトのフォルダーで実行する。

```powershell
.\.local\start-app.ps1 -PersonalApi -Restart
```

停止は `.\.local\stop-app.ps1`。個人用APIを使わない場合は `-PersonalApi` を外す。待受先は `127.0.0.1`、DBは `.local/dev.sqlite3`。個人用キーはGit管理外の `.local/personal-api.env` に置く。

## 訪問した予定を残す

「旅をつくる」のタイムラインで、次の予定の「訪問済みにする」を押す。表示中の開始・終了時刻を確認して記録すると、場所・時刻・滞在時間が保護される。時間や予算の変更、交通経路の更新、自動調整は、この記録を保持して未訪問の予定を変更する。

訪問済みがある間は出発地・日付・出発時刻を変更できない。修正が必要なら、最後の訪問の「訪問済みを解除する」から順に解除する。通常の「ひとつ前に戻す」では訪問記録を取り消さない。解除後も場所と滞在時間の固定は残る。実際の訪問時刻の自動計測は行わない。

## JSONで保存・復元する

旅程の上にある「JSONを書き出す」で、日帰り旅程をファイルに保存する。条件、出発・帰着地、施設の座標、固定内容、施設ごとの費用、訪問記録を含む。

「JSONを読み込む」でファイルを選ぶと、日付・発着地・件数・時間・予算を確認できる。「この旅程を読み込む」で現在の旅程を置き換える。キャンセル時や不正なファイルの場合は現在の旅程を保持する。上限は200KB・8施設。読み込んだ移動時間は概算、交通費は未確認として扱い、必要に応じて交通経路を再検索する。AI要約、提供元の説明文、APIキーは書き出さない。

## 駅名から探す

条件欄の出発駅で「駅名で探す」を開き、駅名を入力して「駅を検索」を押す。同名駅は都道府県を見て選択する。「出発駅に戻る」を外すと、帰着駅も独立して検索できる。検索中のキャンセルは元の選択を保持する。入力するだけでは通信しない。

個人用の `EKISPERT_API_KEY` が必要。検索は駅すぱあとの鉄道駅データを使用し、最大5候補まで表示する。
