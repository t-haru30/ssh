# 公開候補データの確認

2026-10-12に次の候補を修正した。全国の全施設の営業状態を確認済みという意味ではない。

- 北海道の昼食候補「古母里（廃業）」を除外し、周辺で昼食先を選ぶ未確定の予定へ変更した。未確定の昼食は施設検索やAI提案の候補には含めない。
- NHKスタジオパークを訪問候補から除外した。[NHK財団の事業計画](https://www.nhk-fdn.or.jp/assets/pdf/about/management/2020_jigyou_keikaku.pdf)に、2020年の臨時休館後に再開せず閉館したことが記載されている。残った訪問先の順序、移動区間、所要時間、昼食位置を再計算した。
- 「伏見稲荷大社」の登録点 [node/11174591021](https://www.openstreetmap.org/node/11174591021) は、OSMの `historic=memorial`、`memorial=stele` に該当する同名の案内碑だった。参拝施設として表示しないよう除外し、[node/6865347485](https://www.openstreetmap.org/node/6865347485) の千本鳥居へ変更した。表示名を「伏見稲荷大社 千本鳥居」とし、位置を34.966983,135.7747604へ修正した。大社全域の中心や本殿の位置ではない。[伏見稲荷大社の公式アクセス案内](https://inari.jp/access/)も参照した。

公開データ生成時は、これらの除外対象IDや「廃業」「閉業」「閉館」などの表示を含む施設を検出するとビルドを停止する。元データを再生成した場合も、閉館施設や誤認した案内碑を自動で再公開しないための検査である。施設の追加・再採用時は一次情報とOSMの対象物を確認し、検査と修正理由を更新する。

名称・座標を変更したルートは、地図用座標、全移動区間、時間の合計、出発駅からの距離、昼食位置も合わせて更新する。京都の修正ルートでは、同じ二条城の展望地点が続く構成を見直し、既存候補の京都市学校歴史博物館を途中へ加えた。施設間の移動距離を既存の5km上限内に保つ。公開用のOSM帰属表示と加工データのダウンロードは維持する。
