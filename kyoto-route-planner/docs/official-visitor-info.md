# 公式案内の取得

施設の詳細と出発前チェックでは、施設の公式ページから営業時間・休館日・料金を読み、項目ごとに取得元のリンクを表示します。通常の開館時間、最終入館、祝日の振替、年末年始、展示替えの記載を残します。当日の入場可否の自動判定は行いません。

## 公式URLを探す順序

1. 確認済みの施設情報があれば、その公式URLを使います。
2. OpenStreetMapのID・名称・座標を照合し、website/contact:website等の登録URLを確認します。建物のway/relationはfullレスポンスの形状から位置を照合します。
3. URLが未登録なら、施設に紐づく日本語Wikipedia記事やWikidataを確認します。名称・位置が一致する記事のinfoboxの公式URL欄、またはWikidataの公式サイト登録だけを候補にします。これらの情報から営業時間を転載することはありません。
4. 旧URLが廃止されている場合は、名称・位置が一致する記事に登録された移転先も確認します。

HTTPの転送と短時間のmeta refreshを回数制限内でたどり、利用案内・開館時間を優先して同じサイトの案内ページを最大2ページ確認します。JavaScriptは実行しません。

## 抽出と未確認の扱い

HTMLの見出し・表・定義リスト・画像のaltから項目を抽出します。全角数字、空白入りの見出し、Shift_JISにも対応します。ナビゲーション・過去のニュース・イベントの無料案内・共通券やガイド向け料金を通常案内と混同しないよう、本文の境界を確認します。

一部の項目や案内ページの取得に失敗しても、先に確認できた項目とその出典を保持します。未確認の項目を持つキャッシュは次回の確認時に再取得し、不完全な結果を固定しません。そろった結果は最大6時間再利用します。

案内ページに施設名を明示した臨時休館のお知らせへのリンクがある場合は、同じサイトの告知を最大1件読みます。新着情報の一覧が別ページにある場合は、一覧を1ページだけ確認します。明示された休館期間を確認し、既に終了した期間や別施設の告知を採用せず、通常の休館日とは別に出典付きで表示します。

不足時のGemini検索には、直接確認できた公式URLを参考情報として渡します。検索の要約は直接抽出した項目と分けて表示し、施設や出典の照合が不十分な回答は採用しません。

## 接続と実行の上限

公開DNSの結果を検証して接続先IPを固定し、転送先も改めて検証します。証明書・ホスト名の検証を有効にしたまま、OpenSSLと互換性のないサイトにはcurl-cffiのTLS実装で1回だけ接続を補います。OSの信頼済みCAを使い、プロキシ・自動リダイレクトを無効にしています。

京都市教育委員会の `www.edu.city.kyoto.jp` はサーバー側の証明書チェーンに中間証明書がないため、このホストに限りGlobalSign公式配布の `GlobalSign RSA OV SSL CA 2018` を補います。中間証明書を独立した信頼の起点にせず、OSのルートまで検証します。期限・ホスト名の検証は維持し、実行時の拇印照合に失敗した場合は接続しません。

- 配布元：[GlobalSignの中間証明書一覧](https://jp.globalsign.com/support/rootcertificates/ssl.html)、[証明書](https://jp.globalsign.com/repository/common/cer/gsrsaovsslca2018.cer)
- 同梱先：`backend/app/data/globalsign-rsa-ov-2018.pem`
- SHA-256（DER）：`b676ffa3179e8812093a1b5eafee876ae7a6aaf231078dad1bfb21cd2893764a`
- 有効期限：2028年11月21日。公式サイト側のチェーン修正・証明書更新時に、この補完の要否を再確認します。

1施設の処理は12秒、論理取得は最大8回、転送は最大3回、本文は1MiBまでです。curl-cffiはbackend/requirements.txtに含まれ、新しいAPIキーの設定は不要です。
