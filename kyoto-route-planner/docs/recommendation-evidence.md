# 口コミ・公開情報に基づく推薦理由

全国の候補について、旅程の各施設と「見つける」のルート詳細にある「口コミ・公開情報を調べる」から取得する。地域ごとの固定文ではなく、個人用Gemini APIのGoogle検索連携を使用する。画面表示だけでは検索しない。

## ローカルでの設定

Google AI Studioで取得した個人用キーを、Git管理外の `.local/personal-api.env` の末尾に追加する。

```env
RECOMMENDATION_GEMINI_API_KEY=自分の個人用キー
```

既存のYahoo!・駅すぱあとキーは変更しない。キーをチャット、ソースコード、ブラウザ用環境変数へ貼らない。設定後はプロジェクトのフォルダーで起動する。

```powershell
.\.local\start-app.ps1 -PersonalApi -Restart
```

停止は `.local/stop-app.ps1`。APIを使わず起動する場合は `.local/start-app.ps1 -Restart`。ローカルの専用起動スクリプトは共有サーバーや共有DBへの接続を遮断し、DBは `.local/dev.sqlite3`、待受先は `127.0.0.1` に限定する。キー設定の有無は `/api/recommendations/status` で確認でき、値は返さない。

## 取得と表示

- 対象の施設名・住所・座標だけをGoogleへ送る。旅程全体、旅行日、好み、利用者の現在地、既存キーは送らない。
- 検索に基づくAI回答を、口コミ・公式情報・注意点に分け、本文に対応する出典リンク、取得日、Googleの検索候補とともに表示する。取得日は資料の公開日や更新日とは異なる。
- 回答は全体300字以内、口コミ60字・公式情報50字・注意点50字以内の各1文を目安に生成する。施設の照合情報と参考ページ一覧は折りたたむ。「出典付き」の強調表示は行わず、本文の参照リンクとGoogleの検索候補は保持する。
- 施設名、指定住所がある場合の一致、AIが検索で確認した位置と候補の距離（500m以内）、施設確認の出典を検証する。これは独立した測量・住所DBによる本人確認ではなく、AIによる施設照合を含む。隣接支店などの誤認を完全には排除できないため、訪問前に出典を確認する。
- 口コミが見つからない場合はその旨を表示する。出典がない回答、対応する出典がない説明、所在地の不一致、不完全な応答は要約として表示しない。星評価や口コミ件数は作成しない。
- 営業時間、当日の営業、最新料金、利用者全体の評価は保証しない。料金を旅程の予算へ自動加算しない。施設の選択・固定・滞在時間にも影響しない。
- 結果は表示中のコンポーネントのメモリだけに保持する。DB、ログ、下書き、保存済みルート、しおりへ保存せず、再読み込みすると消える。外部ページの自動巡回や全文保存はしない。

## APIと費用

既定モデルは `gemini-3.8-flash`。必要なら個人用設定に `RECOMMENDATION_GEMINI_MODEL` を設定する。Google検索対応モデルを指定する。

1回のボタン操作につき生成リクエストは1回。再試行は自動で行わない。サーバープロセスごとに20回、同時取得は1件、同一接続元は1分に6回まで。失敗したリクエストも20回の上限へ数える。再起動で回数はリセットされる。金額の上限や日次の予算管理ではない。1回の生成で複数の検索が行われる場合がある。Google側の課金設定・利用量も確認する。

通常の `GEMINI_API_KEY` はこの機能に使わない。専用キーと `VENUE_EVIDENCE_ENABLED=1` の両方が必要で、ローカル専用ランチャーが個人用設定に応じて有効化する。共有サーバーへの反映・デプロイは行っていない。

ローカル通信ガードは、既存のYahoo!・駅すぱあとHTTPS GETに加え、専用キーがある場合だけ `generativelanguage.googleapis.com` の `/v1beta/models/gemini-…:generateContent` へのHTTPS POSTを許可する。任意の外部URL、共有プロキシ、リダイレクトは許可しない。Googleの検索候補HTMLは安全性を検査してから、見た目とリンクを変更せずShadow DOMで表示する。

## 手本に対して残る差分

比較対象：`yorimichi-daytrip-next-v0.13.1-owner-operation.zip` のREADME、planner、app、evidence-view、storage。

| 項目 | 現状と残る作業 |
| --- | --- |
| 推薦理由の根拠 | 全国の施設を検索する入口、出典付きAI要約を追加。手本にある資料の適用期間・価格の確度・公式資料間の矛盾の構造化判定は未実装。手本の根拠データも限定サンプルで、全国の口コミ自動取得が完成しているわけではない。 |
| 訪問済みの扱い | 訪問順に表示中の時刻を記録し、場所・開始・終了・滞在時間を再計算や自動調整から保護。最後の訪問から確認付きで解除可能。実際の時刻の自動計測は行わない。 |
| 旅程の持ち出し | 日帰り旅程の条件・施設・座標・固定・訪問済み記録をJSONで保存・復元可能。読み込み前に確認し、交通情報は未確認として再計算。AI要約やAPI情報は含めない。 |
| 駅名検索 | 出発地と独立した帰着地の両方で自由入力検索可能。駅すぱあとの実データから都道府県付きの最大5候補を表示し、選択した座標を引き継ぐ。手本の通常デモ側はモック。 |
| 制約超過時の修正案 | 超過表示と固定以外の自動調整は実装済み。必要な延長時間・予算額・解除する固定予定を示す具体的な提案と、施設ごとの滞在時間の最小・最大値の精緻化は未実装。 |
| 実際の訪問可否 | 当日の営業・臨時休業・入場条件と、各施設での滞在を織り込んだ区間ごとの実ダイヤ確認は未実装。手本の通常デモも実際の訪問可否を保証しない。 |
