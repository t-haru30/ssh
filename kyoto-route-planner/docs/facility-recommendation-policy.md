# 施設カタログと推薦方針

施設マスターは `backend/app/data/facility_catalog.json`。実験版と提出版で同じデータを使い、旅程サンプルとは独立して管理する。バックエンド検索と公開用 `osm-places.json` の生成元にする。初回911件を全件見直し、さらに60件を追加した（計971件）。既存旅程や保存DBは削除しない。

## 2026年10月15日の全国拡張と口コミ条件

上記971件に5,680件の基礎候補を追加し、計6,651件とした。追加内訳は観光施設3,470件、飲食店・カフェ2,210件。通常の31県は観光50件＋飲食30件、主要都市・観光地域を含む16都道府県は観光120件＋飲食80件を追加する。対象は北海道、宮城、東京、千葉、神奈川、石川、長野、静岡、愛知、京都、大阪、兵庫、奈良、広島、福岡、沖縄。県内では定番施設と県庁所在地の起点周辺を優先する。

これは**高評価確認済み施設の件数ではない**。独立したOSMの基本情報を保有する基礎候補数であり、推薦可能な件数とは分ける。有名観光地の定番枠を除き、推薦の都度Google Placesで評価4.2以上・口コミ50件以上・営業中を照合できた施設のみを候補に渡す。評価不明、API失敗、同名別支店の疑い、閾値未満は通過させない。定番枠も既存の閉業・確認保留判定は維持する。

画面側でも、APIが返した候補を未確認のローカル施設で補わない。通信失敗・中止・候補不足時はその状態を表示して再検索できるようにする。Geminiだけが失敗した場合は、サーバーで同じ選別条件を通過した通常候補を利用できる。

東京の実Gemini確認では、施設座標をモデルに再出力させた結果、元データとのずれで推薦全体を拒否する問題を再現した。選択出力を施設IDに限定し、名称・座標は検査済みDBから取得する方式へ変更した。過去のHTTPエラーの応答詳細は残っておらず原因の断定はできないため、安全なステータス記録と回数制限付きの一時エラー再試行も追加した。実APIで定番観光と昼食付きの両方が成功し、浅草寺・東京スカイツリーや、口コミ条件を照合した「いせ源」「神田錦町 更科」を含む旅程を確認した。

Googleの評価値・件数・レビュー本文を施設マスター、SQLite、Gemini入力へ保存・転記しない。評価は当該リクエスト内の選別だけに使用し、保存する施設名・座標・分類はOSM由来。実APIの検索結果には上限があるため、条件を満たす全施設を網羅するものではない。広域の人気順検索に加え、食事候補が不足した場合は独立候補の正式名を最大6件照合する。既存の月次利用上限を共有し、上限到達時も未確認施設で穴埋めしない。

チェーン飲食店はブランド属性、地域チェーンを含む名称辞書、支店・本店等の表記、全国データ内の同名複数所在地で除外する。同名の無関係な個人店まで外す場合がある保守的な判定であり、全店の経営関係を公式サイトで調査した結果ではない。元から保存されていたチェーンのIDは履歴のため残すが、推薦対象外にする。

出典は[Geofabrikの日本OSM抽出データ](https://download.geofabrik.de/asia/japan.html)。nodeだけでなくway・relationの施設本体を抽出し、県境、記念物・入口・施設部分、重複を照合した。way・relationの座標は形状の代表点であり、入口や乗降地点ではない。基礎候補の収録自体は営業継続・人気を保証しない。

- `backend/scripts/extract_catalog_expansion.py`: 日本PBFから独立データを抽出
- `backend/scripts/expand_facility_catalog.py`: チェーン・県境・重複を照合し追加。`--apply`なしはプレビューのみ
- `facility-expansion-review.csv` / `facility-expansion-review.json`: 追加・除外判断の記録
- `/facility-catalog.html`: 都道府県・観光/飲食・今回の追加分で絞り込み
- [Google Placesの保存制限](https://developers.google.com/maps/documentation/places/web-service/policies)

`catalog_kind` は facility（本体）、entrance（入口）、photo_spot（撮影地点）、monument（記念碑・標柱）、facility_part（施設の一部分）、other（その他）。本体以外は通常の自動推薦から外し、明示的に希望された場合は候補にできる。OSMの分類と名称を照合した分類であり、全件の現地確認を意味しない。原爆ドームなど独立した訪問対象は、一般の標柱と区別する。

`recommendation_tier` は classic（定番）、regional（地域の見どころ）、hidden（穴場）。出典の信頼度や保存回数とは別の編集属性。`tier_basis` と `review_reason` に判断根拠を保持する。知名度・混雑の実測データではなく、地域の代表的施設・特定分野や地域史の小規模施設などを分ける編集判断である。

通常は定番・地域・穴場を6:3:1、穴場希望時は2:3:5の順序配分で候補を提示する。各区分の不足、距離・テーマ・所要時間、明示された希望によって実際の旅程比率は変わる。指定範囲内の定番を近距離の候補だけで打ち切らない。

検索範囲・テーマ等を満たす定番観光地が少ない場合（3件と旅程の基本立ち寄り数の大きい方に満たない場合）は、地域の見どころ・穴場まで候補を広げる。人気順検索で照合できなかった施設を正式名で追加照合する。飲食店の追加照合と合わせて最大6件とし、月次上限と評価4.2以上・口コミ50件以上の条件は維持する。通常候補の組み立てでは、明示された希望とテーマを優先したうえで、ほかの旅程でまだ使っていない施設を選び、同じ定番をすべての旅程に入れない。Geminiにも定番を必須にせず多様な組み合わせを選ぶよう伝える。条件を通過した施設が足りない場合は、未確認施設で補わない。

保存済みであることや保存回数は加点しない。保存データから同じ施設を読み直しても、OSM IDに対応するマスターの分類を利用する。閉業・情報矛盾等の利用可否チェックは推薦の人気評価とは独立して続ける。

今後は各地域の定番施設と編集分類を個別に追加する。座標は施設の代表点であり、入口を保証しない。営業時間・営業状態・人気順位を今回の分類だけで保証するものではない。

## 2026年10月14日の全件見直し

元の911件を名称・地域・種類・重複・推薦可否の観点で見直した。905件のnodeはOSM本体APIの複数ID取得で照合し、残る6件は前回取得したway/relationの出典を利用した。追加60件は各施設の周辺をOSM本体APIで取得し、名前だけが一致する停留所・案内板・自転車貸出所を排除した。OSMのID、座標、主要分類、照合日をマスターに保持する。

全47都道府県に自動推薦可能な定番があることをテストで確認する。971件の内訳は定番99件、地域の見どころ742件、穴場130件。推薦可否は自動推薦753件、明示希望のみ189件、チェーン飲食等の補助候補18件、除外7件、要確認2件、同名・近接の重複統合2件。推薦区分と推薦可否は別軸で、地域の見どころ区分でも記念碑等は通常推薦しない。

東海大学海洋科学博物館は公式サイトの一般公開終了を確認し除外。川村記念美術館は休館発表を踏まえて再開確認待ち、Western villageは廃施設の可能性があり確認待ちとして自動推薦を保留する。バンダイミュージアムは公式サイトで2026年の開館案内を確認しており、閉館扱いにはしない。全施設の公式サイト・営業時間を個別確認したという意味ではない。
